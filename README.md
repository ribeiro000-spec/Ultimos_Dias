# Últimos Dias
Jogo narrativo de sobrevivência no navegador (HTML/CSS/JS puros, sem build; cenários e retratos gerados em SVG, sons sintetizados por Web Audio).
GitHub Pages: suba a pasta, Settings → Pages → branch main / root.
Local: `python3 -m http.server` e abra http://localhost:8000 (módulos ES não funcionam via file://).
